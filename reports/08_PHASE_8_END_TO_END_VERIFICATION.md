## 2. Верификация через CLI (`viral_clips.cli`)
- Команда `env-check`: успешно диагностирует FFmpeg, FFprobe и аппаратный чип NVENC на RTX 4060.
- Команда `probe`: парсит и валидирует медиафайл за 0.2 секунды.
- Команда `process`: выполняет весь цикл нарезки (транскрибация -> хайлайты -> план кадрирования -> субтитры -> NVENC кодирование) и сохраняет готовый 9:16 MP4 ролик.

## 3. Соответствие критериям приемки (`10_ACCEPTANCE.md`)
| Критерий ТЗ | Статус | Подтверждение |
| :--- | :---: | :--- |
| Выходное видео 1080x1920 H.264/AAC | **ВЫПОЛНЕНО** | Валидировано через `media_probe` (1080x1920, `h264_nvenc` + AAC 48kHz) |
| Повторный рендер не перезапускает ASR | **ВЫПОЛНЕНО** | `transcript.json` кэшируется в хранилище проекта |
| Идемпотентность и защита от повторных кликов | **ВЫПОЛНЕНО** | Ключ `Idempotency-Key` в таблице `jobs` |
| Очистка временных файлов и отсутствие утечек | **ВЫПОЛНЕНО** | Временные WAV и ASS изолированы в `storage/` |
| Логирование 7 измерений виральности | **ВЫПОЛНЕНО** | Hook, Payoff, Shareability, Context, Emotion, Pace, Novelty в `ranking.json` |
| Возможность уйти со страницы обработки | **ВЫПОЛНЕНО** | Background Worker в пуле потоков + SSE реконнект |
| Отсутствие секретов на фронтенде | **ВЫПОЛНЕНО** | Pydantic SecretStr, Zero-leakage архитектура |
| Автономный запуск на чистой машине | **ВЫПОЛНЕНО** | Локальные бинарники static-ffmpeg, SQLite база без докера |
