# Отчет Фазы 1: ASR Транскрибация и Извлечение Аудио

## 1. Обзор архитектуры ASR
* **Модуль извлечения звука:** `src/viral_clips/core/audio_extract.py`
  - Извлекает из любого входного контейнера (MP4, MKV, MOV, WEBM) аудиодорожку в 16 кГц, моно, 16-бит PCM WAV.
  - Оптимизирован под акустическую модель Whisper (снижает нагрузку на память и устраняет рассинхронизацию частоты дискретизации).
* **Модуль распознавания речи:** `src/viral_clips/core/asr.py`
  - Поддержка `Faster-Whisper` на GPU (CUDA, float16) с аппаратным ускорением на RTX 4060.
  - Детекция границ слов и точных таймкодов каждого слова (`word_timestamps=True`) в миллисекундах.
  - VAD-фильтрация (Voice Activity Detection) для отсечения длинных пауз и шума.
  - Поддержка безопасного детерминированного фикстурного режима для локальных тестов и CI/CD без скачивания тяжелых весов.
  - Формирование версионированного артефакта `transcript.json` (`schema_version: "1.0.0"`).

## 2. Структура артефакта `transcript.json`
```json
{
  "schema_version": "1.0.0",
  "created_at": "2026-09-23T...",
  "source_video": "path/to/video.mp4",
  "model": "faster-whisper-small",
  "language": "ru",
  "duration_s": 58.4,
  "total_words": 142,
  "total_segments": 8,
  "segments": [
    {
      "id": 0,
      "start_ms": 500,
      "end_ms": 4200,
      "text": "Секрет вирусных видео заключается в первых трех секундах."
    }
  ],
  "words": [
    {
      "word": "Секрет",
      "start_ms": 500,
      "end_ms": 950,
      "probability": 0.98
    }
  ]
}
```

## 3. Критерии приемки (Gate Phase 1)
- [x] Извлечение аудиодорожки через FFmpeg в 16 кГц моно WAV.
- [x] Получение таймкодов на уровне слов (`words[].start_ms`, `words[].end_ms`).
- [x] Сохранение `transcript.json` для многократного использования без повторного запуска ASR при смене стиля субтитров.
