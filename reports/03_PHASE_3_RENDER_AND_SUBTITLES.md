# Отчет Фазы 3: Движок Рендеринга и Караоке-Субтитров

## 1. Архитектура Рендеринга
* **Модули:**
  - `src/viral_clips/core/subtitles.py` — генератор Advanced SubStation Alpha (`.ass`).
  - `src/viral_clips/core/renderer.py` — единый конвейер рендеринга (Single-Pass FFmpeg Filtergraph).
* **Стилистические пресеты субтитров:**
  - `bold_karaoke` (стиль Алекса Хормози): крупный шрифт Arial Bold, неоново-желтая подсветка текущего произносимого слова (`\c&H0000FFFF&`), черная окантовка (outline 4.0), тень (shadow 2.0).
  - `minimalist`: аккуратный белый текст с полупрозрачной подложкой.
  - `hormozi_pop`: капс, ярко-зеленая подсветка ключевых слов.
  - Safe Area: субтитры подняты на 280–320 пикселей от нижнего края (MarginV), чтобы не перекрываться элементами интерфейса TikTok, YouTube Shorts и Reels.
* **Однопроходный рендеринг (One-Pass Render):**
  - Обрезка по таймкодам (`-ss`, `-t`).
  - Преобразование соотношения сторон 16:9 -> 9:16 (1080x1920) согласно `crop_plan.json`.
  - Вжигание ASS-субтитров через фильтр `ass`.
  - Аппаратное кодирование через **NVIDIA NVENC (`h264_nvenc`)** с битрейтом 5000 kbps и пресетом `p4`. Автоматический фолбэк на `libx264` при необходимости.
  - Оптимизация флагом `+faststart` для мгновенного веб-стриминга в браузере.
* **Строгая валидация на выходе:**
  - Проверка разрешения ровно 1080x1920.
  - Наличие аудиодорожки.
  - Декодируемость контейнера и размер > 0 байт.
  - Сохранение манифеста рендера `render_manifest.json` (`schema_version: "1.0.0"`).

## 2. Критерии приемки (Gate Phase 3)
- [x] Генерация субтитров формата ASS с пословным таймингом.
- [x] Однопроходный рендер без промежуточных тяжелых несжатых файлов.
- [x] Аппаратное ускорение через NVENC.
- [x] Выходной формат 1080x1920 H.264 / AAC.
