# AI Viral Clips Generator

## Почему проект имеет смысл
Сильный технический showcase: ASR, LLM, CV, FFmpeg, GPU, queues и storage. Категория уже доказана рынком, поэтому успех зависит не от существования функции, а от качества highlights/reframe и выбранной ниши. Хороший вариант для Russian-first, podcast-first, gaming-first, privacy/local-first или API-first позиционирования.

## Основные пользователи
Создатели контента, подкастеры, стримеры, агентства, SMM-команды.

## Core value
Из длинного видео автоматически получить несколько коротких вертикальных роликов, которые можно реально публиковать без ручного спасения таймингов и кадрирования.

## Non-goals первой версии
Billing, social scheduling, mobile app, collaborative editor, десятки caption themes, Kubernetes, distributed GPU fleet.
